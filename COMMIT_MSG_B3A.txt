## 判定口径（两条证据链一致才删）
1. **浏览器链** `tools/b3f-dead.js`：177 个已构建页 × 4 视口（320/390/800/1440）
   跑 `querySelectorAll`，累计命中 = 0。
2. **静态链** `tools/b3f-static.js` / `b3f-verify-dead.js`：已构建 HTML 原文 +
   `layout.js` / `build-site.js` / `SITE_JS` 三处源码，全部 0 处产出。

⚠️ 「0 匹配」与「匹配但不可见」是两件事，本批只删**前者**。伪元素另需剥壳判定
（首轮不剥壳时 9 条活的 `::before` 规则被误判为死，已修正）。

## 三个**没有**删的（判定为活，与规划清单不一致，以实测为准）
- `.stat b` / `.stat span`：`statsHtml()` 在 layout.js:482 定义、:896 导出，
  **全仓 0 个调用点** —— 这是死函数。但两条规则所在族的容器 `.stats`/`.stat`
  在源码里仍有 1 处字面量，且 R3-1 的历史注释引用它们，故按族保留外壳、只删有
  font-size 的两条。**这一条与规划「删 11 条」不同，我是按实测删的。**
- `.cfg-raw`：build-site.js:1407/1409 有条件产出。实测 Markdown 源里有 **1506 个
  无 key 列表项**（tools/b3f-keyless.js），该分支可达 → 保留。
- `.sr-*`（4 条）：由 SITE_JS 运行期 innerHTML 注入，静态 DOM 恒 0 命中但不是死规则 → 保留。
