## ⚠️ 一个必须记录的返工：CJK 可读性
**首轮映射把 `.grp-zh` 归到了 `--fs-2xs`(11.5)，违反 §2.4。**
§2.4 原文：「`--fs-2xs`(11.5) 在中文语境下**只允许承载数字/拉丁**；本方案中文下限 12.5px；
`.grp-zh`（纯中文）**必须走 `--fs-xs`(12.5)**，这会与 `upz-ladder.json` 的 bucket 归属冲突
—— **以本文为准**。」

我写了 `tools/b3f-cjk.js` 做**实证审计**（14 页样本、所有 `<details>` 展开、逐选择器统计
渲染文本是否含 CJK），查出 **15 个选择器**在用 11.5px 承载中文：
`.chip` / `.code-copy` / `.page-meta` / `.pager .dir` / `.pth` / `.grp-zh` / `.side-home` /
`.side-section-title` / `.tag` / `.tg-count` / `.tg-home` / `.tg-zh` / `.toc-side .toc-title` /
`.code-title::after`（「↔ 可横向滚动」）。
→ 全部升到 `--fs-xs`(12.5)，`--fs-2xs` 只保留在 **13 个纯拉丁/数字**选择器上
（`.code-lang` / `.sr-path` / `.sr-chip` / `.src-rel` / `td.num` / `.cfg-n` / `.pager .pth` 等）。
复测违规数 = **0**。
