## 深色/打印修复（typography H1-1）
hljs token 颜色改为 CSS 变量（--hl-*），在 :root / html[data-theme=dark] /
@media(prefers-color-scheme:dark) html[data-theme=auto] 三处赋值。
修前 auto（默认路径）+ 系统深色下 30/30 token 不达 AA（keyword 仅 2.85:1），
因原代码只写了 html[data-theme="dark"]，永远匹配不到 auto。
修后：dark 5.76–11.35:1、light 5.12–6.75:1、print 5.29–6.97:1。

## 5 个回归缺陷修正（5 个 Agent 独立验证后由红队/裁决发现）
D1【P0】批 1 首版的 sticky 把展开态 TOC 永久钉住：768 档占视口 80.8%、812×375 横屏
  正文只剩 43px、12 个正文块被吞；点目录跳转后标题落点在视口 88–92% 处，横屏标题底边被裁。
  修法：只有**折叠条** sticky，展开态 .toc-side:has(.toc-fold[open]){position:static}
  + ol 限高 min(45vh, 100vh-topbar-96px)。验证：4 个视口被吞块 0、标题被盖 0%。
D2/M1【P0】抽屉打开时因 lockScroll 的 scrollbar-gutter 漂移（与深度成正比，0.95 屏 +490px），
  批 0 在关闭时自愈（净 0），但批 1 首版在 closeDrawer 里 scrollTo(savedY) 把自愈抵消 →
  净漂移永久累积。修法：在 openDrawer 前后各记一次并就地校正，closeDrawer 不再干预。
  验证：390/320 × 0.5/0.95 深度四组，开合 3 次净位移全部 0px。
D5【P1】无 JS 时桌面右栏空白（83 条链接高度全 0）。修法：HTML 保留 open 作无 JS 降级，
  由 JS 在窄屏首帧移除（syncToc 用 null 哨兵保证首帧执行）。
  验证：1440 无 JS 仍可见 24 条链接。
D6【P1】打印态 token 对比度净回归（6/6 不达 4.5:1，最差 1.54，比改前 2/6 更差）——
  变量化漏了 @media print 这条路径。修法：print 下强制回浅色板。验证 5.29–6.97:1。
D7【P1】溢出文字提示依赖 :has()，Firefox<=120/Safari<15.4 不支持 →
  提示 13/13→0。修法：JS 同步给 .code-block 加 is-overflowing class，CSS 双通道。
D9【P1】.src-item:has(:focus-visible){outline} + .src-link:focus-visible{outline:none}
  成对存在 → :has() 不支持时键盘焦点完全不可见（WCAG 2.4.7）。
  修法：默认给链接自身焦点环，用 @supports selector(:has(*)) 才提升为整行描边。

## a11y 修复（b1-a11y 报告 F-1/F-2/F-6）
F-1【SC 3.2.5/2.2.2】syncToc 挂在 resize 且无条件赋值 → 用户手动折叠被 1px 视口变化撤销。
  修法：记 lastIsWide，只在真正跨断点时动手。
F-2【SC 2.4.11】吸顶目录盖住锚点落点（coveredPct=100）。修法：JS 把 TOC 实际高度写入
  --toc-offset，html{scroll-padding-top:calc(topbar+12px+var(--toc-offset))}。
F-6【SC 4.1.2】::before{content:"▸"} 进可访问名（AX 树读作「▸ 本页目录 5」）。
  修法：改用 border 画的三角 + prefers-reduced-motion 降级。
